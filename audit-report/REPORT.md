# تقرير اختبار CardioSense / PulseForge

**13 نوفمبر 2026** · اختبار محلي على Windows · نطاق كامل مع تغطية جزئية لبعض الطبقات

## النتيجة

الفرونت والباك اشتغلوا سوا محليًا. نجح إرسال نبض اصطناعي 84 BPM وأكسجين 97% وعينات ECG من MQTT، مرورًا بالـ API وSQL Server وFastAPI، لحد واجهة المريض عبر SignalR. اتأكدت إن مؤشر Live يختفي عند توقف العينات. سجل الدكتور عرض الملف المعيّن له ودرجة الخطورة، والمريض شاف التقرير من غير الدرجة الرقمية.

**جاهزية النشر ببيانات حقيقية: Not ready.** إعداد MQTT المرفق للتطوير بيعتمد على حساب مشترك. تهيئة اعتمادات مستقلة وACL لكل جهاز على broker النشر، والتحقق من TLS مع الجهاز، ما اتعملوش. تشغيل Docker Compose والاختبار بجهاز فعلي لسه غير متحققين.

## الإصلاحات

- **البناء.** إصلاح تعارض Vitest مع Vite، وفصل TypeScript عن إنتاج ملفات إعداد JavaScript، وتصحيح تسجيل FluentValidation واسم HTTP header في .NET. أضيف lockfile للفرونت وثُبتت تحديثات الاعتماديات التي أزالَت تنبيهات الفحص.
- **الدخول والبيانات.** تثبيت الـ access token قبل تحميل الملف بعد reload، ومنع إعادة محاولة auth عند فشل الدخول، وتنظيف React Query عند تبديل الحساب أو الخروج. اتصلح فلتر المرضى اللي كانت حالة التحميل بتغطي على قيمته.
- **خصوصية التقرير والسجل.** إخفاء رقم الخطورة عن المريض في رد الـ API ونص التقرير وتصدير الواجهة. خُفّض مستوى سجل ASP.NET في Development لتجنب تسجيل query string لاتصال SignalR، واتشالت تفاصيل طلبات حساسة من سجل المتصفح.
- **العرض الحي.** عرض حالة SignalR الفعلية للدكتور، تحذير عند الحاجة لإعادة وضع الأقطاب، وتصفير عينات ECG القديمة عند انتهاء مهلة البث. ضبط MQTT 3.1.1 خلّى broker الاختبار يقبل الاشتراك.
- **قاعدة البيانات.** إضافة أول EF migration، وإتاحة تشغيل اختبارات التكامل على قاعدة اختبار محلية عند عدم توفر Docker.

## حدود التحقق

مفيش baseline بصري للمقارنة الآلية، أو تغطية Firefox/Safari، أو اختبار استعادة backup وحمل MQTT/WebSocket على نطاق الإنتاج. بيانات القراءة كانت اصطناعية وbroker الاختبار اتربط بالـ loopback. عدّاد التحذيرات في البناء وحجم الـ bundle اتسجلوا في طبقات الفحص.

تجربة الفرونت استخدمت الكود الموجود في front-end/CardioSense-Frontend-fixed. فولدر front Deploy خارج نطاق العمل، وملفات ZIP الأصلية لم يُعاد حزمها. جذر المشروع خارج Git.

راجع 01-environment.md لأوامر الإعادة وlayers/ لنتائج الـ15 طبقة. سكربتات المتصفح في tests-audit/ وسجلات الاختبارات تحت audit-report/logs/.
